# 来源案例：夏日坡道 → 夏日疾走

这是本 Skill 的实际来源，不是通用规格。当前仓库是独立扩展的驾驶版；开发时先有“夏日坡道”漫游版，再在独立目录中制作“夏日疾走”，原版目录保持不变。

## 项目演进

1. **参考图与视觉锚点**：用户提供竖幅夏日街道插画。真实可见的是蓝天积云、电线、沿路住宅、坡道及强烈的纵深；交通镜与贩卖机属于三维场景里的扩展设计。先做可漫游的住宅街，以街口、贩卖机、绿荫巷、眺望台四个观察点截图检查。
2. **漫游版**：先前的漫游项目使用本地 Three.js、程序化地形与住宅、实例化植被和本地 PBR 素材，形成连通步行路网。原始参考图仅用于设计参考，没有打包为运行时素材。
3. **驾驶版的基线**：在独立副本里实际启动旧赛车版本，检查输入、暂停、画面与资源错误；基线结果写入开发记录，再改造。项目当时并非 Git 仓库，因此用独立目录与文件记录保留原版。
4. **扩展地图**：共享道路数据驱动中心线、宽度、高度、路面、路肩、路口、碰撞、导航和安全点；住宅街、林间山道、眺望台、海岸公路连为一张图。先验证通行和高差接缝，再密化场景。
5. **游戏系统**：三种不同动力学车型；固定步长驾驶、车身碰撞、镜头避障与救援；自由驾驶、竞速、计时、限时检查点、探索收集五种活动；晴天、黄昏、夜景共用几何；本地存档保存成绩、徽章和外观解锁。
6. **实测与优化**：Node 逻辑测试覆盖路网连续性、车辆、检查点顺序、电脑车、收集去重及坏存档；浏览器流程验证五模式、三车、暂停、设置和资源加载。六个指定机位实机截图用于视觉审阅。记录的中画质 1080p 六个采样点约 47–74 FPS，是当时设备上的结果，不代表所有设备。

## 可参考的模块边界

`src/world-data.js` 和 `road-network.js` 管静态空间；`terrain.js`、`regions.js`、`architecture.js`、`nature.js`、`street.js` 生成画面；`vehicle-config.js` 和 `vehicle-system.js` 管驾驶；`activities.js`、`ai-driver.js` 管模式与对手；`progress.js` 管持久状态；`environment.js`、`camera.js`、`ui.js`、`race-app.js` 负责表现与组合。纯逻辑模块有 Node 测试，交付版通过本地服务器启动。

## 证据与边界

- 可在仓库根目录的 `README.md`、`QA.md`、`ASSETS.md`、`src/`、`tests/` 和 `screenshots/` 核对最终实现、许可与验收。开发计划不代表每项已完成；以项目代码和 QA 为准。
- 用户提供的原始插画与运行时游戏截图应始终区分。截图证明了实际渲染结果，但不证明所有玩家设备上的性能。
- 该项目不包含建筑室内、非赛车 NPC、普通车辆交通或联网玩法；不要在复用 Skill 时自动添加这些功能。
