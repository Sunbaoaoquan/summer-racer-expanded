# 夏日疾走 · 山海之间

独立新版赛车游戏，保留 `summer-district` 与 `summer-racer` 原版目录不变。项目使用本地 Three.js、纹理和模型，默认面向桌面浏览器。

## 在线试玩

发布后可直接访问 [夏日疾走 · 山海之间](https://sunbaoaoquan.github.io/summer-racer-expanded/)。网页使用 HTTPS 提供游戏及项目随附素材，不依赖 `file://` 或第三方资源服务器。

## 启动

也可在本地运行。安装 Python 3 后，在本目录运行：

```text
python serve.py --port 8770
```

浏览器打开 `http://127.0.0.1:8770/`。端口被占用时改用 `--port 8771`。也可以双击 `start.bat`。

## 内容

同一张连通地图包含夏日住宅街、林间山道、山顶观景台和海岸公路。可选晴天、黄昏和夜景；可选晴朗夏日、海岸黄昏、星夜巡游三套环境。玩法包括自由驾驶、街头竞速、计时挑战、限时检查点和探索收集。

小町 K 是灵活小车，海风 S 是均衡跑车，山影 R 是漂移车型。三车首次启动即可使用。首次完成有效挑战解锁夏日拉力涂装，收集 12 枚徽章解锁午夜巡航涂装，24 枚徽章完成探索。成绩按路线和车型保存。

WASD 或方向键驾驶，空格漂移，Shift 氮气，R 救援，C 切换追尾／引擎盖视角，P 或 Esc 暂停。自由驾驶靠近挑战入口并停稳后按 E 进入。主菜单的“原图观景点”按钮在自由驾驶中可用。

## 验证

单元测试：`node --test tests/*.test.cjs`，7 项通过；电脑车已实际模拟完成住宅街短环和山海大环。浏览器测试：`node tests/browser.cjs`，Chrome 154、AMD Radeon(TM) Graphics、1920×1080 启动，无页面错误或 HTTP 资源错误，低画质 1440×810 记录约 51 FPS。

实机视觉截图位于 `screenshots/`：原图观景点、售货机近景、林间山道、山顶观景台、黄昏海岸、夜间住宅街。中画质 1080p 的六个采样点约为 47–74 FPS；夜景住宅街约 48 FPS，达到 30 FPS 目标。不同设备、浏览器和窗口合成器会改变结果。

## 已知事项

场景仍是本地程序化模型，住宅与植被不是照片级扫描资产；海岸水面使用轻量动态波纹。极远处区域会降低细节以保持浏览器性能。建筑室内、NPC、车辆交通和联网功能没有加入。
